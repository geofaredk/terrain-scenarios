description=Sketch dikes, ditches, ponds and other landscape features onto a DEM, non-destructively.
about=Draw terrain modifications straight onto a DEM: raise or lower paths (dikes, ditches), flat pads and basins, interpolated surfaces, and add/subtract relief. Every feature stays editable in a list; the original DEM is never changed. Export the modified DEM as a GeoTIFF for your flood simulation. Requires the Python package scipy, which is included in the standard QGIS installers for Windows and macOS; on Linux, install it with your package manager (e.g. python3-scipy).
